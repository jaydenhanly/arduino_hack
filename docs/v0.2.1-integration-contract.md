# Pixel Shift v0.2.1 integration contract

The external roadmap is the product reference. This release implements its required
four-stage run, companion, and post-victory conversation. Explicit later-iteration
ideas remain deferred. Existing local Gemma packaging is preserved.

## Resolved differences

- Default play has one life, hidden targets, and fresh run seeds. Explicit seeds
  and checkpoint controls are development tools.
- Normal targets are 10 apples, 30 pellets, 3 crossings, 12 asteroid destructions.
  Demo targets are 3, 10, 1, 4. Every transition lasts three seconds.
- Existing advanced Snake hazards remain supported but default profiles disable
  them. Maze completion depends on pellets, not defeating a ghost.
- Grid dimensions remain 24 by 12. Rendering uses 12-pixel cells with origin
  (56, 36). Pixel owns y=192 through 239 of the 400 by 240 logical display.
- One seeded random stream per subsystem avoids presentation affecting gameplay.
- Journal data survives victory until conversation exit; a new run clears all
  journal and conversation state. Three exchanges mean three player selections,
  then a farewell without choices. Button B always skips safely to replay.

## Stage contract

All stages extend RefCounted. Signals: points_earned(amount: int),
life_lost(reason: String), objective_completed, journal_event(kind: String,
tags: Dictionary). All expose stopped, invulnerable, target, get_progress() -> int,
steer(direction: Vector2i), advance(delta: float), snapshot() -> Dictionary,
get_player_position() -> Vector2. Positions returned for drawing use logical
screen pixels. snapshot includes stage, seed, player_position and source objects.

Snake initialize(seed_value: int, options: Dictionary = {}). Other stages use
initialize(source: Dictionary, options: Dictionary = {}). Options contain target,
seed, advanced_hazards, ghost_respawn_seconds, ghost_warning_seconds as needed.
Default standalone Snake behavior may retain its prior 25-apple setup for legacy
tests. GameFlow always supplies the active profile.

Maze preserves body, walls, pellets, ghost, ghost_next, ghost_alive, collected,
started, step(), step_ghost(), walkable(), and reachable_cells() for rendering and
tests. Ghost defeats are non-terminal score events with safe warned respawn.

Frogger and Asteroids implement draw_stage(canvas: Node2D, clock: float) for
procedural visuals within Rect2(12, 32, 376, 156). Frogger exposes player: Vector2i,
crossings and lanes. Asteroids exposes player: Vector2, velocity: Vector2,
asteroids, bullets, destroyed and set_controls(axis: Vector2, firing: bool).
Both wait for the first relevant input before hazards activate.

## Companion contract

scripts/ai/pixel_controller.gd extends Node, owning journal, commentary scheduling,
adapter and conversation lifecycle. Public API:

- begin_run(run_id: int, seed: int)
- observe(stage: String, kind: String, progress: int, target: int, score: int,
  tags: Dictionary = {})
- checkpoint(stage: String, kind: String, progress: int, target: int, score: int)
- begin_conversation()
- select_choice(index: int)
- end_conversation()
- reset()
- tick(delta: float)

Signals: changed, conversation_finished. Exposed display properties: emotion:
String, message: String, thinking: bool, choices: Array[String], conversing: bool,
exchange: int. Expose model_enabled: bool (default true), journal, adapter for
tests. GameFlow calls tick only while activity is not paused/debug-frozen.
Controller must not mutate gameplay or read game nodes. Adapter reuses LlmService.
Local inference may never prevent fallback dialogue, skipping, or replay.

Context contains only validated current-run events and bounded conversation
choices. Model replies are validated to the five emotions, bounded renderable
text, and exactly three distinct choices during selection turns. No dynamic
evaluation, files, network beyond local service, or gameplay authority.

## Ownership during parallel work

- Stage worker: scripts/snake_stage.gd, scripts/maze_stage.gd, its new unit probe.
- Late-stage worker: scripts/frogger_stage.gd, scripts/asteroids_stage.gd, its probe.
- Companion worker: scripts/ai/, scripts/llm/llm_service.gd, tests/ai/.
- Coordinator: config, grid, GameFlow, board, Pixel UI, dev tools, hardware adapter,
  integration probes, documentation and packaging verification.

Workers do not edit shared files outside their ownership. Changed APIs are
communicated before integrating. No board deployment or paid generation occurs
as an incidental part of a worker task.
